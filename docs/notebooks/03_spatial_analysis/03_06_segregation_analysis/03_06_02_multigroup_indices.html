Multigroup segregation indices

Overview

Buffalo has more than two groups, and running a separate two-group index for every pair quickly becomes hard to read (four groups already give six pairs). Multigroup indices answer one question for all groups at once: how much does the composition of each tract differ from the composition of the metro area?

This notebook follows the PySAL segregation tutorial on multigroup indices using geolattice.spatial_analysis.segregation. Multigroup indices here use the four named groups (GROUPS: white, Black, Hispanic, Asian); the heterogeneous other category is left out.

Topics:

  • Diversity is not integration: metro-wide Simpson and entropy
  • Theil’s information theory index \(H\) and each tract’s share of it
  • Multigroup dissimilarity and its link to the two-group index
  • Pairwise dissimilarity matrices
  • Local diversity maps
  • Spatial (kernel-pooled) multigroup indices
  • Validation against PySAL and confidence intervals

Setup

The next cell finds the repository root, puts it on the import path, points DATA at Data/03_spatial_analysis/data_segregation/buffalo, imports geolattice.spatial_analysis.segregation as seg, and loads the data.

Study area and data. The Buffalo-Cheektowaga metropolitan area: Erie and Niagara counties, New York (about 1.17 million people in 2020). Counts come from the U.S. Census Bureau decennial censuses of 2000, 2010, and 2020, by census tract, for five mutually exclusive groups:

Column Census definition
white Not Hispanic or Latino, White alone
black Not Hispanic or Latino, Black or African American alone
hispanic Hispanic or Latino (any race)
asian Not Hispanic or Latino, Asian alone
other Everyone else (other single races and two or more races)

Tract boundaries change between censuses. To compare years on the same units, the 2000 and 2010 counts have been moved onto the 323 tracts of 2020 with dasymetric interpolation weighted by 2020 housing units; notebook 03_07_07 shows how. Tracts with fewer than 100 residents (water, parks, the airport) are dropped. Data/03_spatial_analysis/data_segregation/make_buffalo_data.py rebuilds everything from the Census files in Data/03_spatial_analysis/data_segregation/.

Two map helpers keep every map in the same frame: add_context(ax) draws the county outlines, and metro_and_core(...) shows the whole metro area next to a 30 km window centred on the City of Buffalo, where most tracts are small.

Installation. This notebook needs installation option 2 (core plus spatial analysis): pip install "geolattice[analysis]". See “Installation options” in the GeoLattice README.

Part A: Diversity of the metro area

Let \(P_k\) be group \(k\)’s share of the whole region. Two standard summaries of how mixed the region is:

  • Simpson diversity: the probability two random residents belong to different groups, \(I = 1 - \sum_k P_k^2\).
  • Shannon entropy: \(E = -\sum_k P_k \ln P_k\), maximal (\(\ln K\)) when all \(K\) groups are equal in size.

These describe the region, not how its residents are sorted. A metro area can be diverse and segregated at the same time.

Code 
# ===================================================================
# Part A: Diversity of the metro area.
# Let $P_k$ be group $k$'s share of the whole region. Two standard summaries of how mixed the region
# ===================================================================

def regional_entropy(g, groups):
    P = g[groups].sum() / g[groups].sum().sum()  # sum the selected values
    return float(-(P * np.log(P)).sum())  # return the computed result

        "entropy E": regional_entropy(g, GROUPS),  # run this analysis or plotting step

        "Theil H": seg.theil_h(g, GROUPS)}  # run this analysis or plotting step
    for y, g in tracts.items()  # loop over each year and its tract GeoDataFrame

The metro area has become much more diverse: Simpson diversity rises from 0.28 to 0.39 and entropy from 0.56 to 0.78, as the Hispanic and Asian populations grow and the white share falls. A more diverse region is not automatically a more integrated one; here both happened, but they are separate facts measured by separate indices. Notebook 03_07_04 (Part D) shows that the two are linked here: almost all of the fall in \(H\) comes from the rise in diversity, its denominator.

Part B: Theil’s information theory index \(H\)

Each tract \(i\) has its own entropy \(E_i = -\sum_k p_{ik}\ln p_{ik}\). If people were sorted randomly, every tract would look like the region and \(E_i \approx E\). Theil’s \(H\) (Theil and Finizza, 1971; Reardon and Firebaugh, 2002) is the population-weighted average loss of entropy:

\[H = \sum_i \frac{t_i}{T}\,\frac{E - E_i}{E}.\]

\(H = 0\) when every tract has the regional mix; \(H = 1\) when every tract contains a single group. Because \(H\) is a weighted sum over tracts, each tract’s term \(h_i = \frac{t_i (E - E_i)}{T E}\) is its contribution to metro-wide segregation and can be mapped.

Code 
# ===================================================================
# Part B: Theil's information theory index $H$.
# The metro area has become much more diverse: Simpson diversity rises from 0.28 to 0.39 and
# ===================================================================

def theil_contributions(g, groups):
    c = g[groups].to_numpy(float)  # NumPy array view of the column
    t = c.sum(1); T = t.sum()  # sum the selected values
    P = c.sum(0) / T  # define P
    E = -(P * np.log(P)).sum()  # sum the selected values
    p = c / t[:, None]  # tract share of the focal group within the pair
    Ei = -np.sum(np.where(p > 0, p * np.log(p), 0), axis=1)  # define Ei
    return t * (E - Ei) / (T * E), Ei  # return the computed result

for y in YEARS:  # loop over panel years
    h_i, _ = theil_contributions(tracts[y], GROUPS)  # run this analysis or plotting step
    assert np.isclose(h_i.sum(), seg.theil_h(tracts[y], GROUPS))  # sanity-check an invariant
    print(f"{y}: H = {h_i.sum():.3f}; {(h_i < 0).sum()} of {len(h_i)} tracts are more diverse than the metro (h_i < 0)")  # status line for the notebook reader

h20, E20 = theil_contributions(tracts[2020], GROUPS)  # run this analysis or plotting step

               norm=plt.matplotlib.colors.TwoSlopeNorm(vmin=-lim / 4, vcenter=0, vmax=lim),  # define norm
               label="$h_i$ (negative = more diverse than the metro)")  # define label
plt.show()  # render the figure in the notebook

The map is the opposite of what many people expect. The largest positive contributions come from the white suburban and rural ring, not from the East Side. \(H\) measures departure from the metro mix, and in 2020 that mix is about 73% white. A 97% white suburban tract therefore departs from it almost as much as an 85% Black city tract does, and there are many more such tracts with large populations. East Side tracts contribute modestly, while the West Side and the areas around downtown, where four groups live together, are more diverse than the metro and pull \(H\) down (purple). Segregation is a property of the whole region: the homogeneity of the suburbs is as much part of it as the concentration of Black residents in the city.

Part C: Multigroup dissimilarity

Sakoda’s (1981) generalization of \(D\) sums each tract’s absolute deviation from the regional composition over all groups and normalizes by the region’s own Simpson interaction \(I_s = \sum_k P_k(1-P_k)\):

\[D_{multi} = \frac{\sum_i \sum_k t_i\,|p_{ik} - P_k|}{2\,T\,I_s}.\]

With only two groups this reduces to ordinary \(D\) exactly, which the cell verifies.

\(H\) is always smaller than \(D_{multi}\) for the same data; they use different scales (entropy vs. absolute deviation) and should be compared only across places or years, not with each other. Reardon and Firebaugh (2002) recommend \(H\) as the default multigroup measure because it satisfies the principle of transfers and decomposes additively.

Part D: The pairwise matrix

A multigroup index compresses six pairwise contrasts into one number. Showing the full pairwise dissimilarity matrix alongside it tells the reader which groups drive it.

Code 
# ===================================================================
# Part D: The pairwise matrix.
# $H$ is always smaller than $D_{multi}$ for the same data; they use different scales (entropy vs.
# ===================================================================

def pairwise_matrix(g, groups, index_fn=seg.dissimilarity):
    M = pd.DataFrame(np.nan, index=groups, columns=groups)  # build table M
    for a in groups:  # loop over demographic groups
        for b in groups:  # loop over demographic groups
            if a != b:  # conditional branch
                M.loc[a, b] = index_fn(g, [a, b])  # assign a derived column or cell
    return M  # return the computed result

fig, axes = plt.subplots(1, 3, figsize=(14, 4.2), constrained_layout=True)  # create figure and axes
for ax, y in zip(axes, YEARS):  # loop over panel years
    M = pairwise_matrix(tracts[y], GROUPS)  # define M
    im = ax.imshow(M, cmap="Purples", vmin=0.3, vmax=0.8)  # define im
    ax.set_xticks(range(4), GROUPS, rotation=30); ax.set_yticks(range(4), GROUPS)  # label years on the x-axis
    for i in range(4):  # iterate over the collection
        for j in range(4):  # iterate over the collection
            if i != j:  # conditional branch
                ax.text(j, i, f"{M.iloc[i, j]:.2f}", ha="center", va="center", fontsize=8,  # run this analysis or plotting step
                        color="white" if M.iloc[i, j] > 0.6 else "black")  # define color
    ax.set_title(f"{y}: pairwise D")  # set labels, title, or axis limits
fig.colorbar(im, ax=axes, shrink=0.8); plt.show()  # render the figure in the notebook

In 2000 the matrix is dominated by the Black row: Black residents are highly separated from every other group (0.64 to 0.77). By 2020 the Black-Hispanic and Black-Asian contrasts have fallen to about 0.46 and 0.50, while the Asian-white contrast has risen to 0.59. Black-white remains the largest pair, and the Asian row is the only one that grows. The multigroup indices hide these opposing movements.

Part F: Spatial multigroup segregation

As with the single-group indices, pool each tract’s counts over a kernel neighbourhood and recompute \(H\). The ratio \(H(\text{bandwidth})/H(\text{aspatial})\) reads as “the share of segregation that is still visible at that scale”, the core idea behind Reardon et al.’s (2008) macro/micro segregation comparison.

def pooled(g, groups, bandwidth):
    nb = seg.kernel_weights(g, bandwidth=bandwidth, kernel="gaussian")  # distance-decay neighbourhood weights
    out = g.copy()  # mutable copy so originals stay unchanged
    out[groups] = nb.pooled_counts(g[groups].to_numpy(float))  # assign a derived column or cell
    return out  # return the computed result

Summary

  • Diversity is not integration. Metro-wide diversity rises as the population changes, while Theil’s \(H\) falls; the two answer different questions.
  • Theil’s \(H\) is a population-weighted entropy loss. Its tract contributions sum exactly to the metro value, so they can be mapped to show where segregation is produced.
  • Multigroup dissimilarity reduces to the two-group \(D\) for two groups. Report the pairwise matrix alongside any multigroup index so readers can see which contrasts drive it.
  • Local entropy and Simpson map diversity; the most diverse tracts are not the same as the least segregated region.
  • Kernel-pooled \(H\) shows how much segregation survives at larger scales, separating macro-scale divides from local patchiness.
