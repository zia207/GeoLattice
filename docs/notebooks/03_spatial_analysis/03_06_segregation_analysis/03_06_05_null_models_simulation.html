Null models and simulation for segregation

Overview

A segregation index is only interpretable against a reference: what value would the index take if residents were not sorting by group? That reference is a null model, and simulating it answers three practical questions:

  1. Bias. Even in a metro area where residents choose tracts at random, finite tract populations produce some unevenness. How large is that baseline?
  2. Significance. Is the observed index larger than chance would produce?
  3. Spatial pattern. Given the set of tract compositions, does their arrangement on the map matter?

Each question needs a different null. geolattice.spatial_analysis.segregation.null provides three, all returning a stack of simulated count tables of shape (n_sims, n_units, n_groups). This notebook follows the PySAL tutorial on simulating population groups distributed randomly in space, applied to Buffalo’s census tracts.

Null What is kept What is randomized Tests
evenness_null each tract’s total population group membership of every resident (multinomial with metro shares) whether tracts differ from random draws (bias, aspatial significance)
systematic_null the exact set of tract compositions which tract gets which composition whether the spatial arrangement matters
spatially_constrained_null the set of compositions within each spatial block which tract gets which composition, only within its block whether fine-scale arrangement matters, given the large-scale pattern

Topics:

  • Small-unit bias of the dissimilarity index
  • Simulated “even” metro areas and bias-corrected indices
  • Shuffling tracts across space
  • Spatial blocks and constrained shuffles
  • Choosing the right null for the question

Setup

The next cell finds the repository root, puts it on the import path, points DATA at Data/03_spatial_analysis/data_segregation/buffalo, imports geolattice.spatial_analysis.segregation as seg, and loads the data.

Study area and data. The Buffalo-Cheektowaga metropolitan area: Erie and Niagara counties, New York (about 1.17 million people in 2020). Counts come from the U.S. Census Bureau decennial censuses of 2000, 2010, and 2020, by census tract, for five mutually exclusive groups:

Column Census definition
white Not Hispanic or Latino, White alone
black Not Hispanic or Latino, Black or African American alone
hispanic Hispanic or Latino (any race)
asian Not Hispanic or Latino, Asian alone
other Everyone else (other single races and two or more races)

Tract boundaries change between censuses. To compare years on the same units, the 2000 and 2010 counts have been moved onto the 323 tracts of 2020 with dasymetric interpolation weighted by 2020 housing units; notebook 03_07_07 shows how. Tracts with fewer than 100 residents (water, parks, the airport) are dropped. Data/03_spatial_analysis/data_segregation/make_buffalo_data.py rebuilds everything from the Census files in Data/03_spatial_analysis/data_segregation/.

Two map helpers keep every map in the same frame: add_context(ax) draws the county outlines, and metro_and_core(...) shows the whole metro area next to a 30 km window centred on the City of Buffalo, where most tracts are small.

Installation. This notebook needs installation option 2 (core plus spatial analysis): pip install "geolattice[analysis]". See “Installation options” in the GeoLattice README.

Part A: Why an even metro area does not give D = 0

Under the evenness null every tract has the metro composition in expectation, but each tract is a finite random sample. Sampling noise makes some tracts a little more Black and others a little more white, so \(D > 0\). The smaller the units (or the smaller the groups), the larger this noise floor.

The cell rescales 2020 tract populations from their real size (median about 3,400) down to about 35 people per unit, roughly the size of a census block, and simulates 300 even metro areas at each size.

Code

# ===================================================================

At real tract sizes the noise floor is small: about 0.02 for Black-white and 0.04 for the much smaller Asian-Hispanic pair, far below the observed values (0.69 and 0.43). With block-sized units of a few dozen people it rises to 0.2 for Black-white and 0.4 for Asian-Hispanic, values that would be mistaken for moderate or even high segregation. This is why studies using small units, or small groups, report bias-corrected indices (Allen et al., 2015) or compare with simulated nulls rather than with zero.

B2. Null distributions and bias-corrected indices

Running every index on all simulated metro areas gives its null distribution. A simple bias-corrected value subtracts the null mean from the observed value; the standardized value divides that difference by the null standard deviation.

Code 
# ===================================================================
# B2. Null distributions and bias-corrected indices.
# Running every index on all simulated metro areas gives its null distribution. A simple
# ===================================================================

index_fns = {  # define index_fns
    "D Black-white": lambda c: D_of(c, ["black", "white"]),  # run this analysis or plotting step
    "D Asian-Hispanic": lambda c: D_of(c, ["asian", "hispanic"]),  # run this analysis or plotting step
    "Theil H": lambda c: seg.theil_h(pd.DataFrame(c, columns=ALL_GROUPS), GROUPS),  # run this analysis or plotting step
}
rows, null_store = [], {}
for y in YEARS:  # loop over panel years
    c = tracts[y][ALL_GROUPS].to_numpy(float)  # NumPy array view of the column
    sims = seg.evenness_null(c.sum(1), seg.global_proportions(c), n_sims=499, rng=np.random.default_rng(y))  # reproducible random generator
    for name, fn in index_fns.items():  # iterate key/value pairs
        obs = fn(c)  # define obs
        null = np.array([fn(s) for s in sims])  # define null
        null_store[(y, name)] = (obs, null)  # assign a derived column or cell

                     "p (greater)": seg.permutation_pvalue(obs, null, alternative="greater")})  # run this analysis or plotting step
corrected = pd.DataFrame(rows).set_index(["index", "year"]).sort_index()  # build table corrected
corrected.round(4)  # run this analysis or plotting step

Every observed value lies far outside its null distribution (note the log scale), so the p-values sit at the floor \(1/(n_{sims}+1)\). At tract scale the bias correction is small for Black-white (about 0.02), but it matters for trends in small groups. Of the observed 0.14 decline in Asian-Hispanic dissimilarity, about 0.03 is the shrinking noise floor; the bias-corrected decline is 0.12.

Part C: The systematic null (shuffling tracts)

The evenness null destroys all structure. A different question is whether the observed arrangement of tracts matters, given the tract compositions we have. The systematic null keeps the exact set of compositions and reassigns them to tracts at random.

An aspatial index cannot respond to this null; it is identical in every shuffle. A spatial index can. Below, the spatial statistic is Black-white dissimilarity computed on counts pooled over a 2 km Gaussian kernel (notebook 03_07_01, Part F).

Code 
# ===================================================================
# Part C: The systematic null (shuffling tracts).
# Every observed value lies far outside its null distribution (note the log scale), so the p-values
# ===================================================================

nb20 = seg.kernel_weights(g20, bandwidth=2000)  # distance-decay neighbourhood weights

def pooled_D(counts, nb=nb20, pair=("black", "white")):
    return seg.dissimilarity(pd.DataFrame(nb.pooled_counts(counts), columns=ALL_GROUPS), list(pair))  # two-group dissimilarity index D

sims_sys = seg.systematic_null(counts20, n_sims=499, rng=np.random.default_rng(7))  # null: shuffle compositions across tracts
aspatial = np.array([D_of(s, ["black", "white"]) for s in sims_sys[:50]])  # define aspatial
print(f"aspatial D across 50 shuffles: min {aspatial.min():.4f}, max {aspatial.max():.4f} (observed {D_of(counts20, ['black', 'white']):.4f})")  # status line for the notebook reader

obs_sp = pooled_D(counts20)  # define obs_sp
null_sys = np.array([pooled_D(s) for s in sims_sys])  # define null_sys
print(f"spatial D observed {obs_sp:.3f}; systematic null mean {null_sys.mean():.3f} (sd {null_sys.std():.3f}); "  # status line for the notebook reader
      f"p = {seg.permutation_pvalue(obs_sp, null_sys, alternative='greater'):.4f}")  # run this analysis or plotting step

fig, axes = plt.subplots(1, 2, figsize=(12, 5.6), constrained_layout=True)  # create figure and axes
for ax, (name, c) in zip(axes, [("observed 2020", counts20), ("one systematic shuffle", sims_sys[0])]):  # pair each axis with a year or layer
    g20.assign(s=c[:, 1] / c.sum(1)).plot(column="s", cmap="Purples", vmin=0, vmax=0.9, ax=ax, edgecolor="white", lw=0.2)  # draw geometries or a series on the axes
    add_context(ax); ax.set_title(f"{name}: spatial D = {pooled_D(c):.3f}")  # county outlines and optional city zoom
plt.show()  # render the figure in the notebook

aspatial D across 50 shuffles: min 0.6867, max 0.6867 (observed 0.6867)
spatial D observed 0.620; systematic null mean 0.383 (sd 0.013); p = 0.0020

Aspatial \(D\) is exactly the same in every shuffle. Spatial \(D\) falls from 0.62 to about 0.38 when the same tract compositions are scattered at random: clustering of similar tracts accounts for a large part of the spatially pooled index. The single shuffled map makes the point visually: the same number of mostly Black tracts exists, but they no longer touch each other.

Part D: The spatially constrained null

The systematic null shuffles tracts across both counties, so it compares the real metro area with one in which the East Side has been scattered across Niagara and rural Erie County. Often the large-scale pattern is taken as given and the question is about finer-scale structure: within each part of the metro area, are similar tracts next to each other?

seg.spatial_blocks partitions tracts into contiguous-ish blocks (k-means on centroids, or a regular grid), and seg.spatially_constrained_null shuffles compositions only within each block.

Code 
# ===================================================================
# Part D: The spatially constrained null.
# Aspatial $D$ is exactly the same in every shuffle. Spatial $D$ falls from 0.62 to about 0.38
# ===================================================================

Part E: Calibrating intuition with partial integration

A useful simulation is to mix the observed metro area with an even one: move a fraction \(a\) of every tract’s residents into a random draw from the metro composition. It shows how a given index responds to a known amount of integration, and helps translate “D fell from 0.77 to 0.69” into a more concrete statement.

def partially_integrate(counts, a, rng):
    t = counts.sum(1)  # define t
    even = seg.evenness_null(t, seg.global_proportions(counts), n_sims=1, rng=rng)[0]  # toy city with identical composition everywhere
    return (1 - a) * counts + a * even  # return the computed result

Halving D(Black, white) from its 2020 value would require redistributing about 50% of residents at random.

\(D\) falls almost linearly with \(a\): halving the 2020 Black-white index would take the equivalent of redistributing about half of all residents at random. Theil’s \(H\) falls faster than linearly (it is closer to quadratic in the departures), so the same change in sorting produces a larger proportional drop in \(H\). Keep this in mind when comparing percentage changes across indices: a 20% fall in \(H\) and a 10% fall in \(D\) can describe the same change.

Summary

  • Finite units produce non-zero indices even in an even metro area; the bias grows as units or groups get smaller. Report bias-corrected or standardized values when units or groups are small.
  • The evenness null (multinomial draws with metro shares) tests whether tracts differ from random allocation of residents.
  • The systematic null (shuffling compositions across tracts) leaves aspatial indices unchanged and tests whether the spatial arrangement matters.
  • The spatially constrained null shuffles only within blocks, keeping the large-scale pattern and testing finer-scale structure. Block size sets the scale of the question.
  • Partial-integration simulations show how differently indices respond to the same change.
