Inference for segregation indices

Overview

Notebook 03_07_05 built the null models. This notebook uses them, and the bootstrap, for the three inferential questions applied segregation studies need to answer:

  1. Single value. Is Buffalo’s index larger than chance would produce?
  2. Comparison. Is the index different between two census years?
  3. Uncertainty. What is a credible range for the index, given that neighbouring tracts are not independent?

It follows the PySAL tutorial on single value and comparative inference, using seg.single_value_test, seg.two_value_test, seg.spatial_block_bootstrap, and seg.panel_trend_test. The main difference from PySAL is the bootstrap: resampling individual tracts treats neighbours as independent draws, which understates uncertainty when compositions are spatially autocorrelated. Resampling spatial blocks keeps neighbours together. Buffalo, where most Black residents live in one contiguous area, shows both the value and the pitfalls of doing this.

Topics:

  • Single-value tests against the evenness and systematic nulls
  • Two-sample permutation tests between years
  • Unit bootstrap vs. spatial block bootstrap
  • Choosing the number of blocks when one group is concentrated
  • Paired block bootstrap for change between years
  • Trend tests across a short census panel and their power

Setup

The next cell finds the repository root, puts it on the import path, points DATA at Data/03_spatial_analysis/data_segregation/buffalo, imports geolattice.spatial_analysis.segregation as seg, and loads the data.

Study area and data. The Buffalo-Cheektowaga metropolitan area: Erie and Niagara counties, New York (about 1.17 million people in 2020). Counts come from the U.S. Census Bureau decennial censuses of 2000, 2010, and 2020, by census tract, for five mutually exclusive groups:

Column Census definition
white Not Hispanic or Latino, White alone
black Not Hispanic or Latino, Black or African American alone
hispanic Hispanic or Latino (any race)
asian Not Hispanic or Latino, Asian alone
other Everyone else (other single races and two or more races)

Tract boundaries change between censuses. To compare years on the same units, the 2000 and 2010 counts have been moved onto the 323 tracts of 2020 with dasymetric interpolation weighted by 2020 housing units; notebook 03_07_07 shows how. Tracts with fewer than 100 residents (water, parks, the airport) are dropped. Data/03_spatial_analysis/data_segregation/make_buffalo_data.py rebuilds everything from the Census files in Data/03_spatial_analysis/data_segregation/.

Two map helpers keep every map in the same frame: add_context(ax) draws the county outlines, and metro_and_core(...) shows the whole metro area next to a 30 km window centred on the City of Buffalo, where most tracts are small.

Installation. This notebook needs installation option 2 (core plus spatial analysis): pip install "geolattice[analysis]". See “Installation options” in the GeoLattice README.

Part A: Is the index larger than chance?

seg.single_value_test(gdf, groups, index_fn, null=...) computes the observed index, simulates n_sims metro areas under the chosen null, recomputes the index on each, and returns a one-sided permutation p-value with the usual \(+1\) correction, \(p = (\#\{\text{null} \ge \text{obs}\} + 1)/(n_{sims} + 1)\).

  • For aspatial indices use null="evenness". Under null="systematic" an aspatial index never changes, so the test is meaningless.
  • For spatial indices null="systematic" asks whether the arrangement of tracts matters.

A1. Spatial index against the systematic null

single_value_test passes each simulated count table back to index_fn as a GeoDataFrame with the original geometry, so any spatial statistic works. Here, dissimilarity after pooling counts with a 2 km Gaussian kernel.

Code 
# ===================================================================
# A1. Spatial index against the systematic null.
# All observed values are far above the evenness null, and the p-values are at the floor
# ===================================================================

def spatial_dissimilarity(gdf, groups, bandwidth=2000):
    nb = seg.kernel_weights(gdf, bandwidth=bandwidth)  # distance-decay neighbourhood weights
    pooled = gdf.copy()  # tract table with kernel-pooled group counts
    pooled[groups] = nb.pooled_counts(gdf[groups].to_numpy(float))  # assign a derived column or cell
    return seg.dissimilarity(pooled, groups)  # two-group dissimilarity index D

Part B: Did segregation change between two years?

seg.two_value_test(gdf_a, gdf_b, groups, index_fn) pools the tracts of both datasets, randomly re-splits them into two groups of the original sizes, and recomputes the difference each time. If the two datasets came from the same distribution of tract compositions, the observed difference should look like one of these random splits.

Only the 20-year comparison is clearly significant for dissimilarity (p = 0.005); the decade-by- decade declines of about 0.04 each have p-values of 0.09 and 0.11. Theil’s \(H\) falls more and its decade changes reach p < 0.05. With a decline this gradual, a test that ignores the pairing of tracts has little power, which the next caveat explains.

Caveat. This test treats the two datasets as independent samples of tracts. Here the same 323 tracts appear in both years, so the units are paired, and the test ignores that pairing as well as spatial dependence. It is the test PySAL implements, and a reasonable screen, but the paired block bootstrap in Part D is a better match for a same-tract panel.

Part C: Confidence intervals that respect space

C1. Unit bootstrap vs. block bootstrap

A unit bootstrap resamples the 323 tracts with replacement. A spatial block bootstrap (seg.spatial_block_bootstrap) first groups tracts into spatial blocks, then resamples whole blocks. Because tract compositions are strongly autocorrelated, neighbouring tracts carry overlapping information; the unit bootstrap counts them as independent and produces intervals that are too narrow.

Code 
# ===================================================================
# Part C: Confidence intervals that respect space.
# Only the 20-year comparison is clearly significant for dissimilarity (p = 0.005); the decade-by-
# ===================================================================

def unit_bootstrap(gdf, groups, index_fn, n_boot=999, ci=0.95, seed=0, **kw):
    rng = np.random.default_rng(seed)  # reproducible random generator
    n = len(gdf)  # define n
    vals = np.array([index_fn(gdf.iloc[rng.integers(0, n, n)], groups, **kw) for _ in range(n_boot)])  # define vals
    lo, hi = np.quantile(vals, [(1 - ci) / 2, 1 - (1 - ci) / 2])  # run this analysis or plotting step
    return {"estimate": index_fn(gdf, groups, **kw), "ci_lower": lo, "ci_upper": hi, "boot_distribution": vals}  # return the computed result

y = 2020  # panel year
ub = unit_bootstrap(tracts[y], pair, seg.dissimilarity, seed=3)  # define ub
bb = seg.spatial_block_bootstrap(tracts[y], pair, seg.dissimilarity, n_boot=999, n_blocks=30, seed=3)  # define bb

fig, axes = plt.subplots(1, 2, figsize=(13, 4.8), gridspec_kw={"width_ratios": [0.8, 1.3]})  # create figure and axes
tracts[y].assign(b=bb["blocks"]).plot(column="b", categorical=True, cmap="tab20", ax=axes[0], edgecolor="white", lw=0.3)  # draw geometries or a series on the axes
tracts[y].dissolve(by=bb["blocks"]).boundary.plot(ax=axes[0], color="k", lw=0.8)  # draw geometries or a series on the axes
add_context(axes[0], labels=False); axes[0].set_title("30 k-means blocks")  # county outlines and optional city zoom
axes[1].hist(ub["boot_distribution"], bins=40, alpha=0.6, label=f"unit bootstrap [{ub['ci_lower']:.3f}, {ub['ci_upper']:.3f}]")  # run this analysis or plotting step
axes[1].hist(bb["boot_distribution"], bins=40, alpha=0.6, label=f"block bootstrap [{bb['ci_lower']:.3f}, {bb['ci_upper']:.3f}]")  # run this analysis or plotting step
axes[1].axvline(bb["estimate"], color="k", ls="--", lw=1.5, label=f"estimate {bb['estimate']:.3f}")  # run this analysis or plotting step
axes[1].set(xlabel="bootstrap D(Black, white), 2020", title="Resampling tracts vs resampling blocks"); axes[1].legend(fontsize=8)  # add a legend
plt.tight_layout(); plt.show()  # render the figure in the notebook
print(f"interval width ratio (block / unit): {(bb['ci_upper'] - bb['ci_lower']) / (ub['ci_upper'] - ub['ci_lower']):.2f}")  # status line for the notebook reader
print(f"bootstrap medians: unit {np.median(ub['boot_distribution']):.3f}, block {np.median(bb['boot_distribution']):.3f} (estimate {bb['estimate']:.3f})")  # status line for the notebook reader

interval width ratio (block / unit): 2.67
bootstrap medians: unit 0.685, block 0.678 (estimate 0.687)

The block-bootstrap interval is about 2.7 times wider than the unit-bootstrap interval. Resampling a block pulls in a whole run of similarly composed tracts, which is how the real uncertainty behaves when the pattern is spatially smooth. Both bootstrap distributions are centred close to the estimate here, but they are skewed to the left: replicates that happen to include few East Side tracts produce a much lower \(D\).

C2. How many blocks?

Fewer, larger blocks preserve more dependence but leave few resampling units. In Buffalo there is a second issue: if the blocks are large, one block may hold most of a group. Replicates that leave that block out describe a different metro area altogether. The table reports, for each block count, the largest share of Black residents in any single block.

Code 
# ===================================================================
# C2. How many blocks?.
# The block-bootstrap interval is about 2.7 times wider than the unit-bootstrap interval. Resampling
# ===================================================================

rows = []  # accumulate one summary row per year / group
for k in [5, 10, 20, 30, 50, 80, 160, 323]:  # iterate over the collection
    if k == 323:  # conditional branch
        r = unit_bootstrap(tracts[2020], pair, seg.dissimilarity, n_boot=499, seed=0)  # compute() result with value and CI
        top = tracts[2020].black.max() / tracts[2020].black.sum()  # sum the selected values
    else:
        r = seg.spatial_block_bootstrap(tracts[2020], pair, seg.dissimilarity, n_boot=499, n_blocks=k, seed=0)  # compute() result with value and CI
        top = (tracts[2020].black.groupby(r["blocks"]).sum() / tracts[2020].black.sum()).max()  # sum the selected values
    rows.append({"blocks": k, "largest block's share of Black residents": top,  # append this year/group record
                 "ci_lower": r["ci_lower"], "ci_upper": r["ci_upper"],
                 "width": r["ci_upper"] - r["ci_lower"], "boot median": np.median(r["boot_distribution"])})  # run this analysis or plotting step
blk = pd.DataFrame(rows).set_index("blocks")  # build table blk

fig, ax = plt.subplots(figsize=(7.5, 3.6))  # create figure and axes

With 5 or 10 blocks, a single block holds 70% to 80% of the metro area’s Black residents. Every replicate that draws that block zero times describes a metro area with almost no Black population, so the interval stretches far down and is lopsided. From about 20 blocks the largest block’s share falls to about a quarter and the interval stabilizes at roughly 0.55 to 0.75. With many very small blocks it narrows toward the unit bootstrap, which ignores spatial dependence. For Buffalo, 20 to 50 blocks is a defensible range; this series uses 30. Part D: A paired block bootstrap for change

When both years use the same tracts, resample the same blocks for both years in each replicate and compute the difference. This keeps the pairing (each tract compared with itself) and the spatial dependence, and gives a confidence interval for the change directly. Because the same tracts drop in or out of both years together, the “missing East Side” problem of Part C largely cancels.

Code 
# ===================================================================
# Part D: A paired block bootstrap for change.
# With 5 or 10 blocks, a single block holds 70% to 80% of the metro area's Black residents. Every
# ===================================================================

def paired_block_change(gdf_a, gdf_b, groups, index_fn, n_boot=999, n_blocks=30, seed=0, ci=0.95):
    rng = np.random.default_rng(seed)  # reproducible random generator
    blocks = seg.spatial_blocks(gdf_a, n_blocks=n_blocks, seed=seed)  # define blocks
    ub = np.unique(blocks)  # define ub
    members = {b_: np.where(blocks == b_)[0] for b_ in ub}  # define members
    diffs = np.empty(n_boot)  # define diffs
    for i in range(n_boot):  # iterate over the collection
        rows_ = np.concatenate([members[b_] for b_ in rng.choice(ub, size=len(ub), replace=True)])  # define rows_
        diffs[i] = index_fn(gdf_b.iloc[rows_], groups) - index_fn(gdf_a.iloc[rows_], groups)  # absolute gap between group share schedules
    est = index_fn(gdf_b, groups) - index_fn(gdf_a, groups)  # define est
    lo, hi = np.quantile(diffs, [(1 - ci) / 2, 1 - (1 - ci) / 2])  # run this analysis or plotting step
    return {"change": est, "ci_lower": lo, "ci_upper": hi, "share of replicates < 0": (diffs < 0).mean()}  # return the computed result

Part E: Trend tests on a short panel

seg.panel_trend_test runs a Mann-Kendall test (non-parametric: it only uses the signs of pairwise differences) and reports the Theil-Sen slope (median of pairwise slopes). It needs at least three periods. With census data the panel is short, which limits power severely: even a perfectly monotone series cannot reach a small p-value with few periods.

With three census years the Mann-Kendall p-value can never fall below about 0.30, even for a perfectly monotone decline like Buffalo’s; with four it cannot reach 0.05. For a short panel:

  • Report the Sen slope as the effect size (here about \(-0.0044\) per year, or \(-0.044\) per decade).
  • Use the paired block bootstrap (Part D) to establish that each change is real.
  • Add periods where possible: American Community Survey 5-year estimates give annual tract data since 2009 (with sampling error that must be carried into the analysis), and older censuses can be interpolated onto current tracts as in notebook 03_07_07.

Summary

  • Single-value tests compare an index with a null. Use the evenness null for aspatial indices and the systematic null for spatial ones; with tracts of thousands of people, focus on the effect size rather than the (always tiny) p-value.
  • Two-sample permutation tests compare two datasets but ignore pairing and spatial dependence.
  • The unit bootstrap understates uncertainty when compositions are spatially autocorrelated; the spatial block bootstrap gives wider, more honest intervals. When one group lives in a small part of the map, large blocks give unstable, skewed intervals. Report the number of blocks and how much of each group the largest block holds.
  • For a fixed-boundary panel, a paired block bootstrap of the change is the most direct way to show that segregation moved.
  • Mann-Kendall trend tests have almost no power with three or four census years. Report the Sen slope and bootstrap evidence, and extend the panel where possible.
