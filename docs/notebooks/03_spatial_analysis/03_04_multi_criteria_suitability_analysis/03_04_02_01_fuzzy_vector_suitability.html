Setup

Installation. This notebook needs installation option 2 (core plus spatial analysis): pip install "geolattice[analysis]". See “Installation options” in the GeoLattice README.

Code 
# Display matplotlib figures inline in this Jupyter notebook.
%matplotlib inline

import warnings  # silence benign RuntimeWarnings
from pathlib import Path  # filesystem paths for MCSM sample data

# Third-party numeric / plotting stack used throughout this notebook.
import matplotlib.pyplot as plt  # figure and axes creation for membership maps

import geolattice

if not (ROOT / "Data").is_dir():

warnings.filterwarnings("ignore", category=RuntimeWarning)  # quiet numeric warnings

# Import the fuzzy MCSM module and the named helpers used below / in exercises.

from geolattice.spatial_analysis.multi_criteria_suitability_analysis import (
    SuitabilityAnalysisError,  # typed error for invalid overlay / FIS inputs
    categorical_and,  # Boolean AND (for comparisons)
    categorical_or,  # Boolean OR (for comparisons)
    criteria_count,  # k-of-n counts (for comparisons)
    hybrid_suitability,  # constrained continuous scores
    jaccard_index,  # set similarity for top-quantile agreement
    limiting_criterion,  # weakest membership name under AND
    mamdani,  # rule-based FIS (used in later notebooks / exercises)
    minmax_normalize,  # min-max standardisation helper
    monte_carlo_weights,  # weight uncertainty helper
    overlay,  # fuzzy overlay operators
    percentile_rank_normalize,  # rank-based standardisation
    perturb_weights,  # OAT weight perturbation
    spread_for_small,  # calibrate Small-function spread
    top_quantile_mask,  # top-q Boolean mask from a score
    trapezoidal_mf,  # trapezoid membership for FIS
    triangular_mf,  # triangle membership for FIS
    weighted_fuzzy_overlay,  # weighted fuzzy operators
    weighted_linear_combination,  # WLC for comparisons
)

import geopandas as gpd  # vector GeoDataFrames for counties / hubs

# Load criteria layers and Part I weighted results for side-by-side comparison.
counties = gpd.read_file(str(DATA_DIR / "ny_criteria.gpkg"), layer="counties")  # derived criteria
state = gpd.read_file(str(DATA_DIR / "ny_criteria.gpkg"), layer="state")  # state outline
hubs = gpd.read_file(str(DATA_DIR / "ny_criteria.gpkg"), layer="hubs")  # referral hubs
part1 = gpd.read_file(str(DATA_DIR / "ny_weighted_suitability.gpkg"), layer="counties")  # WLC + Boolean

# Attach Boolean AND flag and WLC score/rank, renaming to avoid clashes.
counties = counties.merge(part1[["GEOID", "suitable_and", "score", "rank"]], on="GEOID")  # join on FIPS
counties = counties.rename(columns={"score": "wlc_score", "rank": "wlc_rank"})  # clearer names


def fuzzy_map(gdf, column, title, ax=None, cmap="RdYlGn"):
    """Plot a continuous membership choropleth (0-1) with a state outline."""
    ax = gdf.plot(column, cmap=cmap, vmin=0, vmax=1, legend=ax is None, ax=ax,
                  edgecolor="white", linewidth=0.3,  # county edges
                  legend_kwds={"shrink": 0.6, "label": "Membership mu"} if ax is None else None)  # colourbar
    state.boundary.plot(ax=ax, color="#00000080", linewidth=0.8)  # state outline
    ax.set_title(title, fontsize=10)  # panel title
    ax.set_axis_off()  # hide axis ticks
    return ax  # return axes for overlays


print(len(counties), "counties")  # confirm feature count

From crisp thresholds to membership functions

Each Module 3 threshold becomes the midpoint (μ = 0.5) of a membership function. Values around the threshold are partly suitable instead of being cut off.

Criterion Crisp rule (Module 3) Fuzzy function Parameters Reasoning
Need index ≥ 100 Large midpoint 100, spread 15 State average = 0.5, and 115 is about 0.89
ICU-bed LQ < 1 Small midpoint 1, spread 3 State rate = 0.5, no beds = 1
Rurality (RUCC) ≥ 4 Linear 1 → 0, 7 → 1 Ordinal code. Large metro = 0, small non-metro or more rural = 1
Distance to hub (km) ≤ 100 Small midpoint 100, spread 4 100 km = 0.5, 50 km ≈ 0.94, 200 km ≈ 0.06

The LQ and need index both take zero or positive values, which Small and Large require. RUCC is ordinal, so a Linear ramp is the simplest honest choice.

Code 
# Define membership-function parameters mirroring the Module 3 crisp thresholds as midpoints.
PARAMS = {
    "need":     dict(func="large",  midpoint=100, spread=15),  # higher need is better
    "capacity": dict(func="small",  midpoint=1.0, spread=3),  # lower ICU LQ is better
    "rural":    dict(func="linear", minimum=1, maximum=7),  # RUCC ramp 1 -> 7
    "access":   dict(func="small",  midpoint=100, spread=4),  # shorter hub distance is better
}

# Evaluate each membership on the county attribute table.
counties["mu_need"] = fz.large(counties["need_index"], 100, 15)  # Large around need=100
counties["mu_capacity"] = fz.small(counties["icu_lq"], 1.0, 3)  # Small around LQ=1
counties["mu_rural"] = fz.linear(counties["rucc"], 1, 7)  # Linear rurality ramp
counties["mu_access"] = fz.small(counties["hub_km"], 100, 4)  # Small around 100 km

MU = ["mu_need", "mu_capacity", "mu_rural", "mu_access"]  # membership column names
counties[MU].describe().round(3)  # summarise membership distributions

Membership curves with the county values

Plotting each curve with the actual county values (the ticks along the bottom) shows where counties fall on each function. It is a useful check that the parameters fit the data’s range.

Code 
# Plot each membership curve with county values as red points (and rug marks).

         ("icu_lq", "mu_capacity", lambda x: fz.small(x, 1, 3), (0, 2.5), "ICU-bed LQ"),

Mapping memberships vs. crisp criteria

Each pair of maps below shows the crisp version of a criterion next to its fuzzy version. The crisp maps have two colors, while the fuzzy maps show gradients, so counties close to a threshold appear as intermediate rather than being forced into pass or fail.

Code 
# Side-by-side crisp vs fuzzy maps for each criterion.
crisp = {
    "mu_need":     counties["need_index"] >= 100,  # crisp need threshold
    "mu_capacity": counties["icu_lq"] < 1,  # crisp capacity threshold
    "mu_rural":    counties["rucc"] >= 4,  # crisp rurality threshold
    "mu_access":   counties["hub_km"] <= 100,  # crisp access threshold

sm = plt.cm.ScalarMappable(cmap="RdYlGn", norm=plt.Normalize(0, 1))  # shared 0-1 colour scale

All five operators are applied to the four memberships.

# Apply all five fuzzy overlay operators to the four membership layers.

The maps show the operator spectrum from Module 5:

  • Sum and OR are close to 1 almost everywhere. Every county is strong on something, so these operators discriminate poorly here.
  • Product is low almost everywhere. Four memberships multiplied together shrink quickly, which makes Product a very strict screen.
  • AND highlights counties where every criterion is at least moderately satisfied.
  • Gamma (0.9) keeps more variation than Sum while being less harsh than Product.

Every metro county scores 0 under Product and Gamma, because μ_rural = 0 makes the product zero. A single zero membership vetoes a location under any operator except Sum and OR.

For a siting decision where every criterion matters, AND or Gamma with a moderate γ are the most useful operators.

Choosing γ

Statistics alone cannot pick γ, but a simple diagnostic shows how much each choice spreads the counties apart. A spread that is too small cannot tell counties apart.

The diagnostic below plots the mean result and the coefficient of variation (CV) against γ. All metro counties have μ_rural = 0, which makes Product, and therefore every Gamma with γ < 1, equal to 0 for them. The CV is therefore computed only over counties with a non-zero result, the ones actually in contention.

Code 
# Diagnose gamma: mean level vs coefficient of variation across gamma in [0, 1].
gammas = np.round(np.arange(0, 1.01, 0.05), 2)  # gamma grid
res = pd.DataFrame({g: fz.overlay(mus, "gamma", gamma=g).values for g in gammas})  # one column per gamma

pos = res[res.iloc[:, 0] > 0]  # counties with non-zero Product (eligible for CV)
stats = pd.DataFrame({"mean": pos.mean(), "cv": pos.std() / pos.mean()})  # level vs discrimination
fig, ax = plt.subplots(figsize=(8, 4))  # gamma diagnostic figure
ax.plot(stats.index, stats["mean"], marker="o", label="Mean combined mu (eligible counties)")  # mean curve
ax.plot(stats.index, stats["cv"], marker="s", label="Coefficient of variation (eligible counties)")  # CV curve
ax.set(xlabel="gamma", title="Gamma overlay: level vs. discrimination")  # labels
ax.legend(); ax.grid(alpha=0.3)  # legend and light grid
plt.show()  # render the figure

As γ rises, the mean combined membership increases and the CV falls. For the eligible counties, the CV drops from about 1.1 at γ = 0 to about 0.4 at γ = 0.7 and 0.15 at γ = 0.9, so near 0.9 the counties become hard to tell apart. Values between about 0.5 and 0.8 keep a useful spread for this dataset. The rest of this module uses γ = 0.7 alongside AND.

Code 
# Adopt gamma = 0.7 as a working compromise and rank counties by that score.

counties["fz_rank"] = counties["fz_gamma07"].rank(ascending=False, method="min").astype(int)  # 1 = best

Which criterion limits each county?

With the AND operator, a county’s combined membership equals its weakest criterion. Identifying that criterion for each county gives a diagnostic map that tells planners what would need to change to make each county more suitable.

# Identify the limiting (weakest) criterion under fuzzy AND for each county.
counties["limiting"] = limiting_criterion({c.replace("mu_", ""): counties[c] for c in MU})  # argmin membership

Fuzzy vs. Boolean vs. weighted (WLC)

How do the three approaches compare? Rank correlation measures agreement on the overall ordering, and the overlap of top sets shows agreement where it matters most.

Code 
# Spearman rank correlations among WLC and fuzzy overlay scores.
comp = pd.DataFrame({
    "WLC (Module 4)": counties["wlc_score"],  # Part I weighted score
    "Fuzzy AND": counties["fz_and"],  # min overlay
    "Fuzzy Product": counties["fz_product"],  # product overlay
    "Fuzzy Gamma 0.7": counties["fz_gamma07"],  # working gamma
    "Fuzzy Sum": counties["fz_sum"],  # sum overlay
})
comp.corr(method="spearman").round(3)  # rank-correlation matrix
WLC (Module 4) Fuzzy AND Fuzzy Product Fuzzy Gamma 0.7 Fuzzy Sum
WLC (Module 4) 1.000 0.740 0.805 0.805 0.547
Fuzzy AND 0.740 1.000 0.977 0.976 0.128
Fuzzy Product 0.805 0.977 1.000 1.000 0.225
Fuzzy Gamma 0.7 0.805 0.976 1.000 1.000 0.228
Fuzzy Sum 0.547 0.128 0.225 0.228 1.000

Gamma and Product produce identical rankings (ρ = 1.000). The fuzzy Sum is almost 1 for every county, so Gamma ≈ 1^γ × Product^(1-γ), which is a monotonic transformation of Product. Here, Gamma changes the values, making them less compressed than Product, but not the order. Gamma and Sum would diverge in ranking only with fewer criteria or weaker memberships.

Several patterns stand out:

  • Chautauqua gets μ_capacity = 0.50 rather than a fail, and its strong need keeps it competitive.
  • Sullivan gets μ_access just under 0.5 at 106 km, so it is penalized slightly rather than eliminated.
  • Hamilton, ranked 1st by WLC, drops to 8th. Its distance to a hub (μ_access = 0.38) can no longer be offset by its excellent need and capacity scores.
  • The Bronx scores high on need but μ_rural = 0. Under AND it drops to 0, because a non-compensatory operator lets the weakest criterion set the result. Under WLC it ranked 12th. Fuzzy AND enforces the program’s rural focus without a separate hard constraint.

This is the main practical advantage of fuzzy overlay: it is non-compensatory like Boolean AND, but graded like WLC.

Key takeaways

  • Crisp thresholds become midpoints of membership functions, which removes hard edges.
  • With four or more criteria, Sum and OR saturate and Product collapses, so AND and moderate Gamma are usually the most informative operators.
  • Fuzzy AND is non-compensatory but graded, and its limiting criterion map is a useful diagnostic.
  • Fuzzy and WLC rankings largely agree on the top counties but differ where compensation matters, such as the Bronx.
