Why sensitivity analysis matters

Every suitability model rests on judgments and imperfect data:

Source of uncertainty Examples in this model
Preference (value judgments) Criterion weights, whether slope matters more than flood risk
Model structure Membership function shape and midpoint, aggregation rule (WLC or fuzzy)
Thresholds Maximum slope of 10%, stream threshold of 4 km²
Data DEM vertical error, cell size, zone boundaries (MAUP)

A map that presents one “best site” without testing these hides how fragile it may be. Decision-makers, regulators, and the public reasonably ask: would the answer change if someone else had chosen the weights?

Two related ideas are used in this module:

  • Sensitivity analysis (SA) asks which inputs the result responds to most. It tells you where to spend effort justifying inputs.
  • Uncertainty analysis (UA) asks how confident we can be in the result, given the plausible range of all inputs. It produces probability and confidence maps.

Sensitivity methods also differ in scope:

Scope Method What it reveals
Local OAT (3) Effect of small changes around the baseline, one input at a time
Global, preference Monte Carlo weights (4) Robustness to the full range of plausible weights
Global, variance-based Sobol and Morris (5) Share of output variance due to each input, including interactions
Data Error propagation, resolution, MAUP (6) Robustness to input data quality and spatial support

A reusable model pipeline

To test the model, it must be possible to re-run it from scratch with different inputs. The functions below rebuild the Module 7 workflow at any resolution: DEM → criteria → constraints → memberships → WLC score.

Code 
# ===================================================================
# Reusable solar-suitability pipeline: terrain criteria, memberships, WLC.
# ===================================================================

def nanmean_filter(a, size):
    """Moving-window mean that ignores NaNs by normalising filled sums by weights."""
    vals = np.where(np.isnan(a), 0, a)  # replace NaN with 0 for summing
    wts = (~np.isnan(a)).astype(float)  # 1 where valid, 0 where NaN
    return ndi.uniform_filter(vals, size) / np.maximum(ndi.uniform_filter(wts, size), 1e-9)  # nan-aware mean


def flow_accumulation(dem, res, left=EXTENT[0], top=EXTENT[3]):
    """D8 flow accumulation (cells) with pysheds, via a temporary GeoTIFF."""
    prof = dict(driver="GTiff", height=dem.shape[0], width=dem.shape[1], count=1, dtype="float32",
                crs=CRS, transform=from_origin(left, top, res, res), nodata=np.nan)  # write profile
    with tempfile.NamedTemporaryFile(suffix=".tif", delete=False) as tmp:
        path = tmp.name  # temporary DEM path for pysheds
    with rasterio.open(path, "w", **prof) as dst:
        dst.write(dem.astype("float32"), 1)  # write elevation band
    g = Grid.from_raster(path)  # open temporary DEM
    r = g.read_raster(path)  # read as pysheds Raster
    cond = g.resolve_flats(g.fill_depressions(g.fill_pits(r)))  # hydrologically condition
    acc = np.asarray(g.accumulation(g.flowdir(cond)), dtype=float)  # upstream accumulation
    os.remove(path)  # clean up temporary file
    return acc  # accumulation in cells


def terrain_criteria(dem, res, stream_km2=4.0):
    """Derive slope, south-deviation, TPI, stream distance, and a feasibility mask."""
    valid = ~np.isnan(dem)  # valid elevation cells
    dz_dy, dz_dx = np.gradient(dem, res)  # elevation gradients
    slope = 100 * np.hypot(dz_dx, dz_dy)  # slope as percent grade
    aspect = (np.degrees(np.arctan2(-dz_dx, dz_dy)) + 360) % 360  # aspect in degrees
    dev = np.abs(((aspect - 180 + 180) % 360) - 180)  # deviation from due south
    win = max(3, int(round(1350 / res)) | 1)  # odd window of about 1.35 km
    tpi = dem - nanmean_filter(dem, win)  # topographic position index (m)
    acc = flow_accumulation(dem, res)  # flow accumulation (cells)
    streams = (acc > stream_km2 * 1e6 / res ** 2) & valid  # stream mask from drainage area
    dist = ndi.distance_transform_edt(~streams) * res  # metres to nearest stream
    dist[~valid] = np.nan  # keep NoData outside DEM
    flat = np.nan_to_num(slope, nan=99) < 0.1  # near-zero slope candidates
    lab, n = ndi.label(flat, structure=np.ones((3, 3)))  # connected flat patches
    ha = ndi.sum(flat, lab, np.arange(1, n + 1)) * res * res / 1e4  # patch areas (ha)
    water = np.isin(lab, np.where(ha >= 25)[0] + 1)  # large flats treated as water
    feasible = valid & ~np.isnan(slope) & (slope <= 10) & (dist > 90) & ~water  # hard constraints
    return dict(slope=slope, dev=dev, tpi=tpi, dist=dist, streams=streams, feasible=feasible)  # criteria dict


PARAM0 = dict(slope_mid=4.0, south_mu90=0.3, tpi_lo=-6.0, stream_mid=300.0)  # baseline membership params


def memberships(c, slope_mid=4.0, south_mu90=0.3, tpi_lo=-6.0, stream_mid=300.0):
    """Stack the four membership rasters for a criteria dict c."""
    asp_sp = -np.log(south_mu90) / 90 ** 2  # Gaussian spread from mu(90 deg)
    mu_exp = np.maximum(fz.gaussian(c["dev"], 0, asp_sp), fz.small(c["slope"], 1, 6))  # exposure OR flat
    return np.stack([fz.small(c["slope"], slope_mid, 4), mu_exp,
                     fz.linear(c["tpi"], tpi_lo, 4), fz.large(c["dist"], stream_mid, 3)])  # (4, rows, cols)


CRITERIA = ["Slope", "Exposure", "Topographic position", "Stream distance"]  # criterion display names
W0 = np.array([0.35, 0.20, 0.15, 0.30])  # baseline weights (sum to 1)


def wlc(M, w):
    """Weighted linear combination of membership stack M with weights w."""
    return np.tensordot(np.asarray(w) / np.sum(w), M, axes=1)  # renormalised weighted sum

Comparison metrics

Every experiment is compared with the baseline using three metrics:

  • Jaccard index of the top 10%: the overlap |A ∩ B| / |A ∪ B| between the top-10% cells of two maps. It answers do we still pick the same best land?
  • Spearman’s ρ: agreement in the overall ordering, computed on a fixed random sample of 20,000 cells for speed.
  • Mean |Δ score|: the average absolute change in score.
Code 
# Shared comparison metrics: Jaccard of top-10%, Spearman, and mean absolute change.
RNG = np.random.default_rng(42)  # reproducible RNG for subsampling
SAMP = RNG.choice(N_CELLS, 20_000, replace=False)  # subsample for fast Spearman
TOPQ = 0.90  # top 10% quantile threshold (keep cells above this)

BASE_TOP = top_quantile_mask(BASE)  # baseline top-10% Boolean mask


def metrics(v, ref=BASE, ref_top=BASE_TOP):
    """Return Jaccard / Spearman / mean |change| of alternate scores vs baseline."""
    return {"jaccard_top10": jaccard_index(top_quantile_mask(v), ref_top),  # top-set overlap
            "spearman": spearmanr(v[SAMP], ref[SAMP])[0],  # rank agreement on subsample
            "mean_abs_change": np.mean(np.abs(v - ref))}  # average absolute score change


print("Top-10% area (km²):", round(BASE_TOP.sum() * 0.0081, 1))  # 90 m cells -> 0.81 ha = 0.0081 km2

One-at-a-time (OAT) weight perturbation

Each weight is changed by δ ∈ {±5, ±10, ±15, ±20%} while the others are rescaled proportionally, so the weights still sum to 1 and keep their relative proportions:

\[w_i' = w_i (1 + \delta), \qquad w_j' = w_j \cdot \frac{1 - w_i'}{1 - w_i} \quad (j \ne i)\]

For example, raising slope from 0.35 to 0.42 (+20%) scales the other three weights by (1 - 0.42)/(1 - 0.35) = 0.892.

OAT has two limitations. It explores only a small neighborhood of the baseline, and it cannot detect interactions. The next two sections remove both limitations.

Monte Carlo weight simulation (Dirichlet)

Why a Dirichlet distribution?

Weights must be positive and sum to 1. Drawing each weight independently and then normalizing gives poorly controlled distributions. The Dirichlet distribution samples directly on this space (the simplex). With concentration parameters \(\alpha_i = \kappa \, w_i^{(0)}\):

  • the mean weight vector equals the baseline \(w^{(0)}\), and
  • the concentration κ controls the spread. A small κ represents wide disagreement about the weights, and a large κ represents near-consensus.

For a weight with mean w, the standard deviation is \(\sqrt{w(1-w)/(\kappa+1)}\).

Code 
# Visualise Dirichlet weight samples at three concentrations (kappa).
fig, axes = plt.subplots(1, 3, figsize=(14, 3.8), sharey=True)  # three kappa panels
for ax, kappa in zip(axes, [10, 50, 200]):
    Ws = RNG.dirichlet(kappa * W0, 5000)  # sample weight vectors around W0
    ax.boxplot(Ws, tick_labels=[c.split()[0] for c in CRITERIA], showfliers=False)  # weight spreads
    ax.scatter(range(1, 5), W0, color="red", zorder=3, label="baseline")  # baseline markers
    sd = np.sqrt(W0 * (1 - W0) / (kappa + 1))  # analytic SD of Dirichlet margins
    ax.set_title(f"kappa = {kappa}  (SD of slope weight = {sd[0]:.3f})", fontsize=10)  # panel title

Running the simulation

The simulation uses N = 1,000 weight vectors with κ = 50, representing moderate disagreement (an SD of about 0.07 on the slope weight). Storing every simulated map would take about 800 MB, so statistics are accumulated in batches:

  • the running sum and sum of squares give the mean and SD of the score,
  • a count of top-10% membership gives the probability of being in the top 10%, and
  • the percentile rank of each cell in each run gives rank stability (mean and SD of rank).

Global sensitivity analysis with SALib

OAT and Monte Carlo show how much the result varies. Variance-based global sensitivity analysis shows which inputs cause the variation, including interactions, with all inputs varying together.

Inputs (factors) and their ranges

Raw importance factors are sampled independently and then normalized. Sampling normalized weights directly would make them dependent, and the Sobol decomposition assumes independent inputs.

  1. Y₁: Jaccard of the top 10% vs. the baseline, measuring how much the selection changes.
  2. Y₂: mean score of the baseline top-10% cells, measuring how good the currently preferred land looks.

Sobol indices

  • First-order index S1 is the share of output variance explained by a factor alone.
  • Total-order index ST is the share explained by a factor including all its interactions.
  • ST - S1 measures how much a factor acts through interactions.
  • ΣS1 < 1 means interactions matter.

Reading the global results.

  • Interactions dominate Y₁. For the Jaccard output, ΣS1 is only about 0.31, so most of the variance comes from interactions, and every ST is much larger than its S1. This is expected for a threshold-based output: whether a cell enters the top 10% depends on the combination of all inputs. For Y₂, the mean score of the preferred land, ΣS1 is about 0.94, so that output is almost additive.
  • The same leading factors from two methods. The TPI and exposure weights have the largest total effects, and Morris μ* ranks them first and second as well. Agreement between methods with different assumptions is strong evidence.
  • Influence is not the same as weight size. The TPI weight is the smallest baseline weight (0.15), yet it is the most influential factor. Its membership varies the most across the study area and is least correlated with the other criteria, so shifting its weight reorders cells the most. Criteria that are nearly uniform, such as slope on this gentle terrain, have little leverage however heavily they are weighted.
  • Transformation parameters matter too. The slope midpoint has a larger total effect than the slope or stream weights. Debates about suitability models tend to focus on weights, but where a membership function puts its midpoint can matter just as much.

Data uncertainty

DEM error propagation

No DEM is exact. Vertical errors of a few meters are typical for 30-90 m national DEMs, and the error is usually spatially autocorrelated: neighboring cells tend to be wrong in the same direction. This matters because slope is computed from differences between neighbors:

  • Uncorrelated noise produces large spurious neighbor differences, which inflate slope and break up streams.
  • Correlated noise shifts neighbors together and has much less effect on slope.

The DEM is perturbed with Gaussian error fields (σ = 2 m), using both uncorrelated noise and noise with a correlation length of about 270 m (Gaussian-smoothed white noise rescaled to σ). The entire pipeline, including stream extraction, is re-run 20 times for each type, with the baseline weights.

Code 
# DEM elevation-error Monte Carlo: uncorrelated vs spatially correlated noise (sigma = 2 m).
def error_field(shape, sigma_m, corr_cells, rng):
    """Gaussian elevation error field with optional spatial correlation (cells)."""
    e = rng.standard_normal(shape)  # white noise
    if corr_cells > 0:
        e = ndi.gaussian_filter(e, corr_cells)  # induce spatial correlation
    return e / e.std() * sigma_m  # scale to target RMSE (metres)

The modifiable areal unit problem (MAUP)

Results that are aggregated to zones depend on how the zones are drawn. This is the MAUP, which has two components:

  • the scale effect: changing zone size changes the result, and
  • the zoning effect: changing zone boundaries at the same size also changes the result.

To demonstrate both, the 90 m suitability is aggregated to square “planning blocks” (mean score per block, requiring at least 50% feasible land):

  1. Scale: blocks of 1, 2.5, and 5 km.
  2. Zoning: 2.5 km blocks with 16 different grid origins, shifted in 630 m steps in each direction.

SCORE = to_map(BASE)  # baseline suitability as a full raster


def zone_means(arr, size, dy=0, dx=0, min_frac=0.5):
    """Mean of arr in square zones of `size` cells, origin shifted by (dy, dx)."""
    rows_, cols_ = np.indices(arr.shape)  # row/col index grids
    zid = ((rows_ + dy) // size) * 10_000 + ((cols_ + dx) // size)  # zone ids
    ok = ~np.isnan(arr)  # valid cells
    df = pd.DataFrame({"z": zid.ravel(), "v": arr.ravel(), "ok": ok.ravel()})  # tidy table
    g = df.groupby("z").agg(mean=("v", "mean"), frac=("ok", "mean"))  # zone stats
    g.loc[g["frac"] < min_frac, "mean"] = np.nan  # drop mostly-empty zones
    return g["mean"].reindex(df["z"]).to_numpy().reshape(arr.shape)  # map-shaped zone means

The “best 2.5 km block” moves across the study area as the grid origin shifts, even though the underlying data never change. When suitability is reported for administrative units, parcels, or planning grids, the result is partly an artifact of the zone boundaries.

Ways to reduce the effect:

  • analyze at the native resolution and aggregate only for reporting,
  • use zones that are meaningful for the decision, such as actual parcels,
  • test several zonings, as done here, and
  • report zone results together with their within-zone variability.

(a) Sensitivity ranking of the criteria

The evidence from every method is combined into one ranking. For each criterion, the following are collected:

  • OAT: the mean loss of top-10% agreement (1 - Jaccard) at ±20%,
  • Sobol ST on Y₁ for the criterion’s weight, and for weight and transformation parameter combined,
  • Morris μ* for the weight, and for weight and transformation parameter combined.

Each method’s scores are ranked, and the ranks are averaged.

Reporting checklist

A credible suitability report should state:

  1. The baseline inputs: weights, membership parameters, thresholds, and data sources with resolution and accuracy.
  2. Local sensitivity (OAT): which weights change the selection, and by how much.
  3. Weight uncertainty (Monte Carlo): the distribution used (here Dirichlet with κ = 50), the robust-core and contested maps, and site rank intervals.
  4. Global sensitivity: Sobol and Morris rankings, including the transformation parameters.
  5. Data uncertainty: the DEM error model and its effect, the resolution chosen and why, and MAUP checks for any zonal reporting.
  6. A recommendation that reflects robustness. For this model, for example: “Site #10 ranks first in about 95% of plausible weightings, and Site #12 is in the top three in about 88%. Site #2 ranks anywhere from 1st to 10th depending on the weights, so its selection should be discussed with stakeholders. All site rankings assume an error-free DEM. Given its sensitivity to DEM noise, the top sites should be verified with higher-resolution elevation data.”

Key takeaways

  • Sensitivity analysis shows what drives the result, and uncertainty analysis shows how confident to be in it. Both are required for a credible decision.
  • OAT with proportional renormalization is a simple first check, but it is local and misses interactions.
  • Dirichlet Monte Carlo produces probability maps (P(top 10%)), rank stability measures, and robust versus contested land. Sites with tight rank intervals make defensible recommendations.
  • Sobol and Morris rank all inputs together. Membership parameters can matter as much as weights.
  • Data uncertainty is not secondary. DEM error, cell size, and zoning can change the answer as much as the weights do.
