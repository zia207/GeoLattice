Target and Anomaly Detection

Detection asks a narrower question than classification: is a particular material present in this pixel, even as a small fraction, against everything else in the scene? Hyperspectral detectors model the background statistically and look for pixels that depart from it, either towards a known target spectrum (target detection) or in any direction (anomaly detection). This notebook finds a small eraser hidden in sugar with a target spectrum taken from a different laboratory scene, and detects sub-pixel targets of known fraction implanted in a Tanager city scene, scoring every detector with ROC curves.

Overview

Background and the Mahalanobis distance

Let μ and Σ be the mean and covariance of the background spectra. A pixel x is unusual when it is far from μ in units of the background spread, measured by the Mahalanobis distance (x − μ)ᵀ Σ⁻¹ (x − μ). Whitening by Σ⁻¹ is what makes hyperspectral detectors powerful: it suppresses directions in which the background naturally varies (brightness, vegetation amount) and amplifies directions in which it does not.

Anomaly detection

  • RX (Reed and Xiaoli 1990) is the Mahalanobis distance to the global background (global RX) or to a ring of pixels around each pixel, excluding a guard window (local RX). No target spectrum is needed, but every rare material is an anomaly, wanted or not.

Target detection

With a target spectrum t:

  • Matched filter (MF): (x − μ)ᵀ Σ⁻¹ (t − μ) / (t − μ)ᵀ Σ⁻¹ (t − μ), normalised so that a pure target scores about 1 and the background about 0; for small fractions the score approximates the target abundance.
  • Adaptive coherence estimator (ACE) (Kraut and Scharf 1999): the squared cosine between the whitened pixel and the whitened target; between 0 and 1 and insensitive to pixel brightness.
  • Constrained energy minimisation (CEM) (Harsanyi 1993): a filter with unit response to the target and minimum average output, using the correlation matrix (no mean removal).
  • Orthogonal subspace projection (OSP) (Harsanyi and Chang 1994): projects out a set of known background signatures, then matches the target.

Evaluating detectors

A detector produces a score map; a threshold turns it into detections. The receiver operating characteristic (ROC) plots the true positive rate against the false alarm rate over all thresholds, and its area (AUC) summarises it. In practice targets are rare, so what matters is the detection rate at a very low false alarm rate (for example one in a thousand pixels).

Detection with GeoLattice

hs.rx (global and local), hs.matched_filter, hs.ace, hs.cem and hs.osp return score maps on the cube grid; a background mask restricts the statistics to chosen pixels and shrinkage stabilises the covariance. hs.detection_roc computes the ROC table with the AUC in its attributes.

Learning objectives

  1. Compute global and local RX anomaly maps and interpret them.
  2. Build a target spectrum from one scene and detect the target in another.
  3. Compare MF, ACE, CEM and OSP and their sensitivity to background statistics.
  4. Implant sub-pixel targets of known fraction and measure detection rates with ROC curves.
  5. Use the matched filter score as an abundance estimate.

Setup

Installation. This notebook needs installation option 5 (core, spatial analysis, spatial statistics, geostatistics and remote sensing): pip install "geolattice[remote-sensing]". See “Installation options” in the GeoLattice README.

import warnings  # warning control
warnings.filterwarnings("ignore")  # hide routine library warnings

from pathlib import Path  # file paths

import numpy as np  # arrays
import pandas as pd  # tables
import matplotlib.pyplot as plt  # figures

import geolattice  # GeoLattice
from geolattice.rsense import hyperspectral as hs  # hyperspectral cubes, readers and tools

plt.rcParams.update({"figure.dpi": 110})  # figure resolution
DATA = Path("../../../../Data/08_remote_sensing/08_05_HyperSpectral")  # data folder next to this notebook
TANAGER = DATA / "Tanger"  # Planet Tanager sample scenes
OUT = Path("outputs")  # results written by this notebook
OUT.mkdir(exist_ok=True)  # create it if needed


def tanager_file(category, product="sr"):
    """Path of a Tanager product (sr or radiance) for a scene category folder."""
    return next((TANAGER / category).glob(f"*/*_ortho_{product}_hdf5.h5"))


print("GeoLattice", geolattice.__version__)  # library version used for this notebook

import re  # wavelengths from file names
from PIL import Image  # PNG band images


def read_png_cube(folder):
    """Stack the *_<wavelength>nm.png band images of a HACARUS scene into a cube."""
    files = sorted(Path(folder).glob("*nm.png"), key=lambda p: float(re.search(r"_(\d+)nm", p.name)[1]))
    wl = [float(re.search(r"_(\d+)nm", p.name)[1]) for p in files]
    return hs.as_cube(np.stack([np.asarray(Image.open(p), dtype="float32") for p in files]), wl, name="dn")


def disc(shape, r, c, radius):
    """Boolean disc mask."""
    rr, cc = np.mgrid[:shape[0], :shape[1]]
    return (rr - r) ** 2 + (cc - c) ** 2 <= radius ** 2


def tpr_at(score, truth, far):
    """Share of target pixels above the threshold that only a fraction `far` of background pixels exceed."""
    s = np.asarray(getattr(score, "values", score), float)
    t = np.asarray(truth, bool)
    ok = np.isfinite(s)
    thr = np.quantile(s[ok & ~t], 1 - far)  # background quantile
    return float(np.mean(s[ok & t] > thr))

The eraser is the brightest spot in both RX maps, but it has competition. Global RX also lights up the camera’s vertical stripes (column to column differences of the push broom sensor, invisible in the band image but rare in the statistics) and parts of the lower pile. Local RX suppresses the stripes, because neighbouring columns share them, but turns every small irregularity in the powder texture into speckle. Only about a third of the eraser disc is detected at a false alarm rate of 1 percent; part of the disc is mixed border pixels. Neither detector knows what the eraser looks like.

A target spectrum from another scene

The rice scene, taken with the same camera, also contains a small eraser. Its spectrum, the mean of a 3 by 3 window at the local RX peak near the annotated position, becomes the target signature for the other scene. Using a signature from a different acquisition is the realistic case: a library or field spectrum is never measured in the image being searched.

Code 
rice = read_png_cube(DATA / "archive/data/rice")
near = disc(rice.shape[1:], 135, 155, 12)  # around the annotated eraser
rxr = hs.rx(rice, mode="local", window=21, guard=7).values
r0, c0 = np.unravel_index(np.nanargmax(np.where(near, rxr, -np.inf)), rxr.shape)  # strongest anomaly there
target = rice.values[:, r0 - 1:r0 + 2, c0 - 1:c0 + 2].reshape(rice.sizes["band"], -1).mean(1)  # eraser spectrum
sugar_rice = rice.values[:, disc(rice.shape[1:], 110, 120, 20)].mean(1)  # rice B around it, for comparison
print("eraser found at", (int(r0), int(c0)), "in the rice scene")
wl = hs.wavelengths(con)
fig, ax = plt.subplots(figsize=(11, 4))
ax.plot(wl, target, lw=2, label="eraser (rice scene) = target")
ax.plot(wl, sugar_rice, label="rice B (rice scene)")
ax.plot(wl, con.values[:, truth].mean(1), "--", label="eraser (contamination scene, for checking only)")
ax.plot(wl, con.values[:, disc(con.shape[1:], 110, 118, 25) & ~disc(con.shape[1:], 110, 118, 12)].mean(1), label="sugar around it")

plt.show()
eraser found at (135, 155) in the rice scene

The rice scene’s eraser is bright between 1450 and 1900 nm and lacks the deep water and O-H absorptions of rice and sugar near 1450 and 1940 nm. The eraser in the contamination scene (shown only to check) is not identical: it is smaller, mixed with the sugar around it and lit differently, so it shows part of the sugar’s 1450 nm dip. The target therefore only approximates what the detectors search for, as in any real application.

Four target detectors

OSP needs signatures to suppress; the mean spectra of the tray and of the three powder piles are used.

With a target signature the detectors beat RX: about half of the eraser disc is found at a false alarm rate of 0.1 percent with MF, CEM and ACE, against a third or less with RX. The score maps also show what limits them: whitening amplifies the camera’s vertical stripes, which are rare in the statistics, so stripes become the main source of false alarms (most visibly in OSP, which suppresses only the four signatures it is given). The truth disc includes mixed border pixels, so no detector reaches a true positive rate of 1. Destriping the cube first (notebook 09_05_02) is the obvious next step.

Implanting sub-pixel targets in a city

To measure detection at known fractions, 40 pixels of the Portland window are replaced by linear mixtures of the original pixel and a target: crushed caliche (calcium carbonate) taken from a well pad in the Permian Basin scene, a material absent from the city. The fractions are spread evenly between 2 and 40 percent.

Code 
urban = hs.drop_bad_bands(hs.read_tanager(tanager_file("urban"), window=(slice(319, 619), slice(285, 585))))
em = hs.read_tanager(tanager_file("energy-mining"), window=(slice(400, 650), slice(350, 600)))
em = em.sel(band=urban["band"])  # same good bands as the urban cube
cd = hs.band_depth(em, 2340, 2270, 2400)["depth"].values  # carbonate feature depth
r, c = np.unravel_index(np.nanargmax(cd), cd.shape)  # deepest carbonate pixel: a caliche pad
caliche = em.values[:, r - 1:r + 2, c - 1:c + 2].reshape(em.sizes["band"], -1).mean(1)  # 3 x 3 mean spectrum

rng = np.random.default_rng(1)
H, W = urban.shape[1:]
flat = rng.choice(H * W, 40, replace=False)  # 40 random pixels
rows_, cols_ = np.unravel_index(flat, (H, W))
frac = np.linspace(0.02, 0.40, 40)  # known target fractions
implanted = urban.copy()
X = implanted.values
for rr, cc, f in zip(rows_, cols_, frac):
    X[:, rr, cc] = (1 - f) * X[:, rr, cc] + f * caliche  # linear mixture
truth_u = np.zeros((H, W), bool); truth_u[rows_, cols_] = True
print("target pixel from the Permian Basin:", (int(r), int(c)), f"| 2340 nm depth {cd[r, c]:.3f}")
fig, ax = plt.subplots(figsize=(11, 3.8))
ax.plot(hs.wavelengths(urban), caliche, lw=2, label="caliche target")
ax.plot(hs.wavelengths(urban), np.nanmedian(urban.values.reshape(urban.sizes["band"], -1), 1), label="Portland median")
ax.set(xlabel="Wavelength (nm)", ylabel="Reflectance", title="Target and background"); ax.legend()
plt.show()
target pixel from the Permian Basin: (210, 21) | 2340 nm depth 0.175

ROC curves

The background statistics are estimated from all pixels, including the 40 targets, as they would be in a real search. Every detector gets the caliche spectrum; OSP suppresses five N-FINDR endmembers of the original window.

Summary and exercises

Key points

  • Whitening by the background covariance is what makes hyperspectral detectors sensitive to small targets.
  • RX needs no signature but flags every rare material; local RX favours small objects in uniform surroundings.
  • With a target signature, even one from another acquisition, MF, ACE and CEM detect targets far more selectively than RX; OSP depends on how well its undesired signatures describe the background.
  • Implanted targets of known fraction give honest ROC curves: detection is reliable above a few percent fraction in a city at 30 m, and the matched filter score estimates the fraction.
